# Cloud Computing Final Project — File Sharing Web App on AWS

This project is a practical implementation of cloud computing principles using *Amazon Web Services (AWS)*. It demonstrates how to deploy a simplified file-sharing web application with real-world AWS components and configurations.

## Project Overview

The web application allows users to upload and download files securely via a Flask-based interface hosted on an EC2 instance. The app uses S3 for storage, IAM for secure access, and VPC for networking.

### Key AWS Services Used
- *Amazon EC2* – to host the web application
- *Amazon S3* – for file storage
- *IAM* – to manage secure access between services
- *VPC, Subnet, IGW, Route Table* – to configure the network environment

## Features
- Upload files via a simple HTML form
- Securely store and retrieve files from an S3 bucket
- IAM role-based access without exposing credentials
- Organized network setup using a custom VPC and subnet
